# MicroDevices

Конфигурации для различных устройств на микроконтроллерах в том числе
на которые можно "накатить" linux.

## de10-nano
Макетная плата с Altera Cyclone V SoC на борту. Altera является
микросхемой ПЛИС (FPGA) с ARM ядром, стандартный дистрибутив альтеры
мне не очень нравится. Поэтому этот скрипт помогает накатить на неё
ArchLinux arm с "ванильным" ядром с включенными нектороми опциями *(тут
описать каие опции, там fpga2hps и.т.д)*.
